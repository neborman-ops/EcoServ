### Mod Features:

*   Economy system - Allows players to trade with each other.
*   Sub-worlds system - Adds support for creating and managing custom sub-worlds/dimensions.
*   <span>Roles and tags</span> - Features custom player roles, tags, and text badges.
*   <span>Server configuration</span> - Offers flexible settings to tweak server mechanics.
